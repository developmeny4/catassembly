# SYNTAX

## declare events

examples

```
event WhenButtonPressed(object "globalid"): {
    log("oh oh soru go visit soru.rbx");
}
```

```
event WhenWebsiteLoaded():
    log("no braces!!");
```

## actions

examples

```
...
{
    log("logged message");
    warn("warning");
    err("faulty code fix it now");
}
```

```
...
{
    set(var, 2);
    repeat(3): {
        add(var, 3);
        log("var is currently {var}");
    }
}
```
